# 引力跳板 · 星际弹弓轨道规划游戏

一款以**引力弹弓（重力助推）**为核心机制的原创轨道规划游戏。玩家为深空探测器编排动作序列——点火变轨、耐心等待、在木星/土星等行星影响球内完成收紧的双曲飞掠——用最省的燃料把探测器送到火星、外太阳系，最终挣脱太阳引力飞出太阳系。

## 玩法

- **5 个关卡**由易到难：火星飞掠 → 小行星带穿越 → 木星引力捕获 → 土星远航（双弹弓接力）→ 星际逃逸
- 三种动作按顺序编排：
  - **等待**：让后续动作推迟 N 天执行
  - **点火**：指定方向（角度）与 ΔV 消耗燃料
  - **弹弓**：选择目标行星与近心点 b（正负决定绕行方向），探测器进入行星影响球时自动结算
- **物理引擎**：简化 N 体模型（太阳引力 RK4 积分 + 双曲飞掠公式），行星沿真实太阳系轨道参数做圆轨道运动
- **评分**：三星 ≤ 55% 燃料预算、二星 ≤ 80%、通关得星
- **成绩体系**：每次通关生成**可追溯成绩记录**（完整动作计划 + 轨迹 + 事件 + 里程碑），
  最佳成绩表以 `best_record_id` 指向对应记录，支持一键轨迹回放；旧版存档自动迁移
- **防重复提交**：执行任务颁发一次性 `submit_token`，相同令牌（或完全相同的动作序列）
  并发/重试提交只落一条记录；星级由服务端复算，客户端无法谎报
- **交互**：实时轨迹预览、滚轮缩放/拖动平移、回放动画、策略提示、关卡成绩榜

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 一键启动（自动挑选空闲端口并打开浏览器）
npm run dev
```

启动后访问控制台输出的地址（如 `http://127.0.0.1:8072`），或直接按 `npm run dev` 自动打开的页面。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system` | 天体参数、关卡信息、最佳成绩摘要（含 `best_record_id`） |
| POST | `/api/preview` | 实时预览轨迹（不评分、不落库） |
| POST | `/api/run` | 执行任务并评分，返回完整轨迹与一次性 `submit_token`（不落库） |
| POST | `/api/submit` | 幂等提交成绩：服务端重新模拟/评分并落库为可回放记录；相同 `submit_token` 或相同动作序列去重 |
| GET | `/api/levels/{id}/records` | 关卡成绩榜（星级↓ 燃料↑ 耗时↑，默认 20 条，不含轨迹） |
| GET | `/api/records/{id}` | 成绩记录详情：动作 + 轨迹 + 事件 + 里程碑（前端轨迹回放用） |
| POST | `/api/score` | 旧版接口兼容：自报分数，生成不可回放的 legacy 记录 |

### 成绩与幂等设计

```
前端编排动作 ──POST /api/run──▶ 服务端积分+评分，返回 submit_token
                              │
            POST /api/submit（带令牌）  ◀── 网络超时可安全重发
                              ▼
   服务端重新积分/评分（拒绝客户端自报星级）
   ├─ run_id = submit_token（UNIQUE）；无令牌时 = 规范化动作的内容哈希
   ├─ 失败任务不进成绩榜；成功才写 score_record（含轨迹 JSON）
   └─ 条件 UPDATE 最佳成绩：星级↓ → 燃料↑ → 耗时↑，更优才晋级
```

- 并发安全：写事务由进程锁串行化，最佳更新用单条条件 SQL（`UPDATE ... WHERE 新成绩严格更优`），
  并发提交不会出现“较差成绩覆盖较好成绩”；`run_id` 唯一约束兜底竞态，撞键即回放首条结果。
- 旧存档兼容：启动时检测旧版 `level_score` 表结构，自动 `ALTER TABLE` 补列，并为历史最佳成绩
  回填 `legacy:<id>` 占位记录（`replayable=false`，界面上标注“旧档”，重新通关即生成可回放记录）。
- 关卡解锁仍沿用上一关 ≥ 1 星；`/api/system` 的最佳成绩摘要里带 `best_record_id`，
  关卡选择页与游戏内 HUD 均可一键「▶ 回放最佳」。

## 物理模型说明

- 距离 AU、时间 天、速度 AU/天（1 AU/天 ≈ 1731.5 km/s）
- 弹弓结算：入轨相对速度 v_inf、近心点 r_p 下，偏转角 δ = 2·asin(1/(1 + r_p·v_inf²/μ))，相对速度大小守恒（能量守恒）
- 行星间互不摄动；探测器在弹弓事件之间只受太阳引力（RK4）
- 近心点小于行星半径会解体；燃料耗尽或超时判负
